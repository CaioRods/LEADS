Vamos começar em 3 minutos!

═══════════════════════════════════════════════════════════════════════════════
PASSO 1: INSTALE (Se ainda não instalou)
═══════════════════════════════════════════════════════════════════════════════

1. Abra PowerShell ou CMD
2. Navegue até: cd C:\Users\[seu-usuario]\Desktop\ProspecApp
3. Execute: npm install

(Espere terminar a instalação)

═══════════════════════════════════════════════════════════════════════════════
PASSO 2: INICIE A APLICAÇÃO
═══════════════════════════════════════════════════════════════════════════════

Na mesma janela do PowerShell/CMD, execute:

    npm start

📌 Aguarde 5-10 segundos até a janela do ProspecApp abrir

═══════════════════════════════════════════════════════════════════════════════
PASSO 3: CARREGUE DADOS DE EXEMPLO (OPCIONAL)
═══════════════════════════════════════════════════════════════════════════════

Se quiser começar com 10 leads de exemplo do Regente Feijó:

1. Feche a aplicação ProspecApp
2. No PowerShell/CMD, estando na pasta ProspecApp, execute:

    cp exemplo-dados.json dados.json

3. Se uma janela perguntar sobre sobrescrever, clique SIM
4. Inicie novamente: npm start

Agora você terá 10 leads de exemplo para testar!

USANDO COM SEUS LEADS DO REGENTE FEIJÓ
═══════════════════════════════════════════════════════════════════════════════

Você tem 3 maneiras:

MANEIRA 1: Adicionar Manualmente (5 minutos)
──────────────────────────────────────────────────────────────────────────────
1. Clique em "Novo Lead"
2. Copie dados do arquivo "Leads_Regente_Feijo.csv"
3. Preencha os campos
4. Clique "Adicionar Lead"

Repita para cada lead (é rápido!)

MANEIRA 2: Usar Dados de Exemplo (Imediato)
──────────────────────────────────────────────────────────────────────────────
1. Feche a aplicação
2. Execute: cp exemplo-dados.json dados.json
3. Inicie novamente: npm start

Pronto! 10 leads carregados para testar.

MANEIRA 3: Script de Importação (Avançado)
──────────────────────────────────────────────────────────────────────────────
Se tiver muitos leads em CSV:
1. Crie um script Python ou Node.js
2. Converta CSV para JSON
3. Substitua dados.json

MANTENDO SEUS DADOS SEGUROS
═══════════════════════════════════════════════════════════════════════════════

Seus dados são salvos em:
C:\Users\[seu-usuario]\AppData\Roaming\ProspecApp\dados.json

Backup Regular:
1. Clique em "Exportar"
2. Clique em "Exportar CSV"
3. Guarde o arquivo em local seguro (Dropbox, Google Drive, etc)

Backup Manual:
1. Copie o arquivo dados.json
2. Guarde em outro lugar

TROUBLESHOOTING RÁPIDO
═══════════════════════════════════════════════════════════════════════════════

❌ "npm: comando não encontrado"
→ Instale Node.js em https://nodejs.org/ e reinicie

❌ "Aplicação não abre"
→ Execute: npm install && npm start

❌ "Dados sumiram"
→ Restaure do backup CSV que você exportou

❌ "Erro ao salvar"
→ Feche outras abas/janelas acessando a pasta, reinicie
