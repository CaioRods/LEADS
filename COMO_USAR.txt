6️⃣  SOLUÇÃO DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════════════

❌ "npm não é reconhecido"
──────────────────────────────────────────────────────────────────────────────
Solução: Node.js não está instalado ou não está no PATH
1. Instale Node.js em https://nodejs.org/
2. Escolha versão LTS (recomendada)
3. Reinicie o computador
4. Tente novamente

❌ "A aplicação fecha ao abrir"
──────────────────────────────────────────────────────────────────────────────
Solução:
1. Abra PowerShell/CMD na pasta do projeto
2. Execute: npm install
3. Execute: npm start
4. Verifique mensagens de erro

❌ "Dados não estão sendo salvos"
──────────────────────────────────────────────────────────────────────────────
Solução:
1. Feche a aplicação
2. Verifique permissões de escrita da pasta
3. Delete arquivo dados.json
4. Reinicie a aplicação (será recriado)

❌ "Não consigo importar dados"
──────────────────────────────────────────────────────────────────────────────
Solução: No momento, adicione leads manualmente. Para importação em massa:
1. Exporte do aplicativo (aprenda a estrutura)
2. Use um script Python para processar CSV
3. Importe o JSON gerado
