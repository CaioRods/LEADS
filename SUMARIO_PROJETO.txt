✅ APLICATIVO DESKTOP (Electron)
   Um aplicativo profissional para Windows/Mac/Linux para gerenciar sua
   prospecção de clientes com interface moderna e intuitiva.

✅ RECURSOS IMPLEMENTADOS:
   • Dashboard com estatísticas em tempo real
   • Gerenciamento completo de leads (CRUD)
   • Sistema de status para acompanhar progresso
   • Histórico de atividades/interações
   • Busca e filtro avançado
   • Exportação de dados em CSV
   • Base de dados local em JSON
   • Interface responsiva e moderna
   • Menu principal e modal detalhado
